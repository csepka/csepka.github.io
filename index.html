FPGA-Based AI Acceleration for Reconfigurable Intelligent Surfaces

Master's Thesis Research | Cal Poly

Developing an FPGA-based hardware control architecture for reconfigurable intelligent surfaces (RIS), enabling programmable wireless environments for next-generation communication systems. The research investigates hardware-efficient AI inference for real-time beamforming and adaptive RIS configuration.

  • Designing a scalable digital control architecture for a 10×10 RIS array with 2-bit phase control per element.
  • Implementing FPGA-based control logic and serial shift-register interfaces using SystemVerilog.
  • Investigating machine learning approaches for channel-aware RIS phase configuration and beam selection.
  • Developing an experimental feedback architecture integrating FPGA control, RF measurements, and optimization algorithms.

Technologies: AMD Kria KV260, SystemVerilog, FPGA, Python, MATLAB, Machine Learning, RF Systems
